# Java с нуля за 3 месяца

Курс для тех, кто никогда не программировал. Начинаем с самой первой программы, к концу февраля 2027 пишем свой веб-сервис на Spring Boot.

Темп быстрый: каждый день новая тема, много примеров и задач. Занимаемся вдвоём, у каждого свой компьютер и своя ветка в git. Как всё поставить и как работать с ветками — [SETUP.md](SETUP.md).

## Как занимаемся

- Каждый рабочий день — одна тема, 1–2 часа.
- Порядок дня: читаешь урок и **сам перепечатываешь примеры** в песочницу (не копируй — руками запоминается быстрее) → отвечаешь на вопросы (ответы под спойлером) → решаешь задачи, пока все тесты не станут зелёными.
- Задачи со звёздочкой ★ — посложнее. Не вышло сразу — вернись к ним завтра.
- Пятница — день практики: одна задача побольше на всё, что прошли за неделю. Хороший момент посмотреть решения друг друга.
- Новые уроки готовит Claude по просьбе «урок» и кладёт в `main`. По просьбе «проверь» он смотрит решения и ответы в твоей ветке.

Где что лежит:

```
days/NNN-тема.md                 уроки
src/main/java/dayNN/             задачи — здесь пишешь решения
src/test/java/dayNN/             тесты: проверяют задачи, их не трогаем
src/main/java/sandbox/           песочница: пробуй что хочешь
progress.md                      твой журнал и заметки
```
