# Java за 3 месяца

Цель: к концу февраля 2027 уверенно писать на Java и собрать свой бэкенд на Spring Boot.
Старт — 25.11.2026. Опора — то, что уже знаешь по PHP: где Java похожа, а где ведёт себя иначе.

## Как занимаемся

- Каждый рабочий день — одна тема, примерно час-полтора.
- День: читаешь урок → отвечаешь на вопросы (сначала сам, потом сверяешься с ответом под спойлером) → решаешь задачи, пока тесты не станут зелёными.
- Пишешь мне «урок» — готовлю следующий день. «Проверь» — смотрю решения и ответы, отмечаю тему и пишу итог в журнал.
- Пятница блока — день повторения: одна задача побольше на всё, что прошли за неделю.

Где что лежит:

```
days/NNN-тема.md        уроки
src/main/java/dayNN/    задачи (заготовки с TODO)
src/test/java/dayNN/    тесты к задачам — их не трогаем
sandbox/dayNN/          эксперименты, можно ломать
```

## Окружение

Как поставить всё с нуля на другом компьютере — [SETUP.md](SETUP.md).

- **JDK** — Eclipse Temurin 25 LTS, `C:\Program Files\Eclipse Adoptium\jdk-25.0.5.10002-hotspot` (прописан в `JAVA_HOME` и `PATH`; терминалы, открытые до установки, его не видят — открой новый).
- **IDE** — IntelliJ IDEA: File → Open → `C:\projects\java-learning`, проект откроется как Maven. В File → Project Structure → SDK должна стоять 25.
- **Сборка** — Maven через обёртку `mvnw.cmd`, ставить Maven отдельно не нужно:

```powershell
.\mvnw.cmd test
```

```powershell
.\mvnw.cmd test "-Dtest=day01.*Test"
```

  Первая — все тесты, вторая — один день. Кавычки обязательны: без них PowerShell режет аргумент на точке.
- **Кириллица в терминале.** Если `java Hello.java` печатает `???` — это кодировка консоли (локаль Windows английская). Выполни `chcp 65001` в этом окне терминала или запускай `java -Dstdout.encoding=UTF-8 Hello.java`. В IntelliJ и в выводе `mvnw` всё и так нормально.
