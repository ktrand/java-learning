# День 3. Арифметика

Сегодня: в каком порядке Java выполняет действия, что получается, когда в одном выражении встречаются целые и дробные числа, какие ещё задачи решает остаток от деления, как делить с округлением вверх и что будет при делении на ноль. Потом готовые математические функции `Math` (модуль, максимум, степень, корень, округление) и проценты со скидками. В конце — 7 задач.

Все примеры можно вставлять в `main` песочницы `sandbox/Playground.java` и запускать.

## 1. Пять действий

| Знак | Действие | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (оба целые — только целая часть) |
| `%` | остаток от деления | `7 % 2` | `1` |

Чем запись в Java отличается от школьной:

- Умножение — только звёздочка `*`. Ни `x`, ни точки, и пропускать знак нельзя: школьное `2(3 + 4)` в Java пишется `2 * (3 + 4)`.
- Знака степени нет. `^` в Java есть, но означает совсем другое (раздел 10). Степень — функция `Math.pow`, о ней в разделе 7.
- Минус перед числом или скобкой работает как обычно: `-5 + 3` → `-2`, `-(5 + 3)` → `-8`.

## 2. Порядок действий

Как в школе:

1. скобки;
2. `*`, `/` и `%` — у них одинаковое старшинство;
3. `+` и `-`.

Действия одного старшинства выполняются **слева направо**.

```java
System.out.println(2 + 3 * 4);          // 14 — сначала 3 * 4
System.out.println((2 + 3) * 4);        // 20 — скобки первыми
System.out.println(10 - 4 - 3);         // 3  — слева направо: (10 - 4) - 3
System.out.println(10 - (4 - 3));       // 9
System.out.println(100 / 10 / 2);       // 5  — (100 / 10) / 2
System.out.println(100 / (10 / 2));     // 20
System.out.println(2 * 3 % 4);          // 2  — (2 * 3) % 4 = 6 % 4
System.out.println(2 + 3 * 4 - 6 / 2);  // 11 — 2 + 12 - 3
```

Сомневаешься — ставь скобки. Лишние скобки не ошибка, а подсказка тому, кто будет читать код.

### Снова ловушка со строкой

```java
System.out.println("Итого: " + 2 * 150 + 3 * 120);    // Итого: 300360
System.out.println("Итого: " + (2 * 150 + 3 * 120));  // Итого: 660
```

Умножения выполнились первыми: получились 300 и 360. Дальше плюсы идут слева направо. `"Итого: " + 300` — это текст плюс число, значит, склейка: `"Итого: 300"`. Потом к тексту приклеилось `360`. Сумму, которую нужно именно сложить, бери в скобки.

## 3. Целые и дробные в одном выражении

Правило из урока 2: если в действии участвует хотя бы одно дробное число, результат дробный. Но Java считает **по шагам**, и правило работает на каждом шаге отдельно:

```java
System.out.println(7 / 2 * 2.0);   // 6.0
System.out.println(7 * 2.0 / 2);   // 7.0
```

В первой строке первый шаг — `7 / 2`. Оба числа целые, получается `3`. Потом `3 * 2.0` → `6.0`. Половинка потерялась ещё на первом шаге. Во второй строке первый шаг — `7 * 2.0` → `14.0`, и дальше всё считается в дробных.

```java
System.out.println(1 / 3 * 3);     // 0   — 1 / 3 = 0, а 0 * 3 = 0
System.out.println(1.0 / 3 * 3);   // 1.0
```

Отсюда правило: **дробное число должно появиться до первого деления**. Пиши `2.0` вместо `2` или ставь `(double)` перед первой переменной.

Дробный результат нельзя положить в `int`:

```java
int k = 10 / 4.0;      // ошибка: possible lossy conversion from double to int
double m = 10 / 4.0;   // можно, m = 2.5
```

### Как Java печатает дробные числа

```java
System.out.println(10 / 3.0);       // 3.3333333333333335
System.out.println(96.0);           // 96.0   — у double всегда есть точка
System.out.println(1234567.0);      // 1234567.0
System.out.println(10_000_000.0);   // 1.0E7  — это 1.0 × 10⁷
System.out.println(0.0001);         // 1.0E-4 — это 1.0 × 10⁻⁴
```

`E` значит «умножить на 10 в степени». Очень большие (от 10 миллионов) и очень маленькие (меньше 0.001) дробные числа Java печатает именно так. Число при этом правильное, просто записано коротко. В последней цифре `3.3333333333333335` — та самая неточность дробных из урока 2. Убрать хвост из цифр поможет округление (раздел 7).

## 4. Остаток от деления: ещё приёмы

В уроке 2 было: `x % 2 == 0` — число чётное, `200 / 60` и `200 % 60` — минуты и секунды. Вот ещё.

### Цифры числа

`% 10` даёт последнюю цифру, `/ 10` отрезает последнюю цифру. Комбинируя их, можно достать любую:

```java
int n = 1234;
System.out.println(n % 10);         // 4 — единицы
System.out.println(n / 10 % 10);    // 3 — десятки: 1234 / 10 = 123, 123 % 10 = 3
System.out.println(n / 100 % 10);   // 2 — сотни:   1234 / 100 = 12,  12 % 10 = 2
System.out.println(n / 1000);       // 1 — тысячи
```

### Счёт по кругу

Часы на циферблате идут по кругу: после 23 — снова 0. Остаток от деления делает такой круг сам:

```java
System.out.println((22 + 5) % 24);   // 3  — сейчас 22 часа, через 5 часов будет 3 ночи
System.out.println((50 + 25) % 60);  // 15 — стрелка на 50 минутах, через 25 минут — на 15
```

Если счёт начинается не с нуля, а с единицы (дни недели: понедельник — 1, воскресенье — 7), делают так: отнять 1, посчитать по кругу, прибавить 1 обратно.

```java
int today = 3;                                  // среда
System.out.println((today - 1 + 100) % 7 + 1);  // 5 — через 100 дней будет пятница
```

### Отрицательные числа

```java
System.out.println(-7 / 2);                // -3 — дробная часть отбрасывается
System.out.println(-7 % 3);                // -1 — у остатка знак первого числа
System.out.println(Math.floorMod(-7, 3));  // 2  — остаток, который не бывает отрицательным
```

Пригодится, когда считаешь по кругу назад. Сейчас 2 часа ночи, сколько было 5 часов назад?

```java
System.out.println((2 - 5) % 24);              // -3 — такого часа нет
System.out.println(Math.floorMod(2 - 5, 24));  // 21 — правильно
```

## 5. Деление с округлением вверх

10 человек едут на такси, в машине 4 места. Сколько машин вызвать?

```java
int people = 10;
int seats = 4;
System.out.println(people / seats);   // 2 — двое остались на улице
```

Целое деление отбрасывает остаток, а здесь нужно округлить **вверх**: 3 машины. Для целых чисел есть формула `(a + b - 1) / b`:

```java
System.out.println((people + seats - 1) / seats);   // 3
```

Почему работает: к людям добавили «почти полную машину» — на одного меньше, чем мест. Если людей ровно поровну (8 на 4 места), добавки не хватит на лишнюю машину: `(8 + 3) / 4` → `2`. Если остался хоть один человек — добавка дотянет до ещё одной машины.

Второй способ — функция `Math.ceil` («округлить вверх», раздел 7): `(int) Math.ceil((double) people / seats)` → `3`.

## 6. Деление на ноль

```java
int x = 5 / 0;
System.out.println(x);
```

Такой код Java пропустит (IntelliJ только подчеркнёт), но при запуске программа **упадёт**:

```
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at sandbox.Playground.main(Playground.java:6)
```

Это **исключение** — сообщение о том, что программа не может продолжать работу. Как читать: `ArithmeticException` — ошибка в арифметике, `/ by zero` — деление на ноль, `Playground.java:6` — файл и номер строки, где это случилось. Строки после ошибки уже не выполнятся. Остаток от деления на ноль (`5 % 0`) падает так же. Исключения подробно — на день 27.

С дробными числами программа не падает, но лучше от этого не становится:

```java
System.out.println(5.0 / 0);    // Infinity  — бесконечность
System.out.println(-5.0 / 0);   // -Infinity
System.out.println(0.0 / 0);    // NaN       — «не число» (Not a Number)
```

Дальше бесконечность и `NaN` испортят все расчёты, где они участвуют. Вывод один: на ноль не делить. Как проверить число заранее — на день 6, в уроке про условия.

## 7. Готовые функции Math

В Java есть набор готовых математических функций. Все они начинаются с `Math.` — напиши это в IntelliJ, и она покажет список. Функцию **вызывают**: имя, а в скобках через запятую — числа, с которыми ей работать. Результат можно напечатать, положить в переменную или использовать в выражении.

### Модуль, максимум, минимум

```java
System.out.println(Math.abs(-5));                 // 5   — модуль: убирает минус
System.out.println(Math.abs(3 - 10));             // 7   — расстояние между 3 и 10
System.out.println(Math.max(3, 7));               // 7   — большее из двух
System.out.println(Math.min(3, 7));               // 3   — меньшее из двух
System.out.println(Math.max(3, 7.5));             // 7.5 — одно дробное, значит, результат дробный
System.out.println(Math.max(Math.max(4, 9), 2));  // 9   — из трёх: функция внутри функции
```

`Math.max` и `Math.min` принимают ровно два числа. Для трёх — вложенный вызов, как в последней строке: сначала большее из 4 и 9, потом большее из него и 2.

Где это нужно в жизни:

```java
int total = 500;
int discount = 700;
System.out.println(Math.max(0, total - discount));   // 0 — сумма не уходит в минус

int bonuses = 300;
System.out.println(Math.min(bonuses, 250));          // 250 — бонусов списали не больше суммы чека
```

### Степень и корень

```java
System.out.println(Math.pow(2, 10));   // 1024.0 — 2 в степени 10
System.out.println(Math.pow(5, 2));    // 25.0   — 5 в квадрате
System.out.println(Math.sqrt(16));     // 4.0    — квадратный корень
System.out.println(Math.sqrt(2));      // 1.4142135623730951
System.out.println(Math.PI);           // 3.141592653589793 — число π, не функция, скобки не нужны
```

`Math.pow` и `Math.sqrt` всегда возвращают `double`, даже если результат целый: `1024.0`. Нужно целое — приведи: `int p = (int) Math.pow(2, 10);` → `1024`. Квадрат часто пишут проще: `x * x`.

```java
double r = 5;
System.out.println(Math.PI * r * r);            // 78.53981633974483 — площадь круга
System.out.println(Math.sqrt(3 * 3 + 4 * 4));   // 5.0 — гипотенуза треугольника 3, 4, 5
```

### Округление

| Функция | Что делает | `3.7` | `3.2` | `-3.7` |
|---|---|---|---|---|
| `Math.round(x)` | к ближайшему целому | `4` | `3` | `-4` |
| `Math.floor(x)` | вниз | `3.0` | `3.0` | `-4.0` |
| `Math.ceil(x)` | вверх | `4.0` | `4.0` | `-3.0` |
| `(int) x` | отрезать дробную часть | `3` | `3` | `-3` |

Что важно запомнить:

- Ровно половину `Math.round` округляет вверх, то есть к большему числу: `Math.round(2.5)` → `3`, `Math.round(-2.5)` → `-2` (−2 больше, чем −3).
- `Math.round` возвращает `long`, поэтому `int r = Math.round(2.7);` — ошибка. Пиши `long r = Math.round(2.7);` или `int r = (int) Math.round(2.7);`.
- `Math.floor` и `Math.ceil` возвращают `double`: `3.0`, а не `3`.
- Для отрицательных `Math.floor` и `(int)` дают разное: `-4.0` и `-3`.

### Округлить до двух знаков после точки

Готовой функции нет. Приём: умножить на 100, округлить, разделить на `100.0`.

```java
double x = 3.14159;
System.out.println(Math.round(x * 100) / 100.0);   // 3.14
System.out.println(Math.round(x * 10) / 10.0);     // 3.1  — один знак
System.out.println(Math.round(x * 100) / 100);     // 3    — ошибка в делителе!
```

По шагам: `3.14159 * 100` → `314.159`, округлили → `314`, разделили → `3.14`. Делить нужно именно на `100.0`: `Math.round` вернул целое, а целое на целое — снова целое (третья строка).

Нули в конце Java не печатает: `2.50` выйдет как `2.5`. Как напечатать ровно два знака — в уроке про строки (день 12).

### Случайное число

`Math.random()` возвращает случайное дробное число от 0 до 1 (ровно 1 не бывает). Из него получают целое в нужных пределах:

```java
int dice = (int) (Math.random() * 6) + 1;   // кубик: от 1 до 6
System.out.println(dice);
```

`Math.random() * 6` — от 0 до 5.999…, `(int)` отрезает дробь — от 0 до 5, `+ 1` — от 1 до 6. Каждый запуск — новое число. Скобки здесь важны: `(int) Math.random() * 6` всегда даёт 0, потому что `(int)` превращает в целое само случайное число (а оно меньше 1), и только потом умножение. Случайные числа понадобятся в игре «угадай число» на день 10.

## 8. Проценты и скидки

15 % от 640 — это `640 * 15 / 100`. В целых числах важен порядок: **сначала умножай, потом дели**.

```java
System.out.println(640 * 15 / 100);   // 96 — 9600 / 100
System.out.println(640 / 100 * 15);   // 90 — 640 / 100 = 6, и 6 * 15 = 90
System.out.println(90 * 15 / 100);    // 13 — точно было бы 13.5, дробь отброшена
System.out.println(90 / 100 * 15);    // 0  — 90 / 100 = 0
```

В дробных числах порядок не так важен:

```java
System.out.println(640 * 0.15);          // 96.0
System.out.println(640 * 15 / 100.0);    // 96.0
```

Частые расчёты:

```java
int price = 640;
int percent = 15;
System.out.println(price - price * percent / 100);   // 544 — цена со скидкой 15 %

int cost = 200;
System.out.println(cost + cost * 30 / 100);          // 260 — закупка 200 плюс наценка 30 %

System.out.println(3 * 100 / 8);                     // 37   — 3 гостя из 8 — это сколько процентов
System.out.println((double) 3 / 8 * 100);            // 37.5 — то же точно
```

## 9. `++` внутри выражения

В уроке 2 `count++` стоял отдельной строкой. Его можно написать и внутри выражения, но тогда важно, с какой стороны плюсы:

```java
int a = 5;
int b = a++;   // b = 5, a = 6 — сначала отдал старое значение, потом увеличил
int c = ++a;   // c = 7, a = 7 — сначала увеличил, потом отдал
```

Это путает даже опытных программистов. Правило простое: пиши `a++` отдельной строкой, а не внутри других действий.

## 10. Частые ошибки

Ошибки, на которые Java ругается:

| Код | Сообщение Java | Что не так |
|---|---|---|
| `int x = 2(3 + 4);` | `';' expected` | пропущен знак умножения: `2 * (3 + 4)` |
| `int y = 5 x 3;` | `';' expected`, `not a statement` | умножение — это `*`, а не `x` |
| `int r = Math.round(2.7);` | `incompatible types: possible lossy conversion from long to int` | `round` возвращает `long`: `long r = …` или `(int) Math.round(2.7)` |
| `int p = Math.pow(2, 3);` | `incompatible types: possible lossy conversion from double to int` | `pow`, `sqrt`, `floor`, `ceil` возвращают `double` |
| `int k = 10 / 4.0;` | `incompatible types: possible lossy conversion from double to int` | результат дробный |
| `math.max(3, 5)` | `cannot find symbol` … `variable math` | `Math` пишется с большой буквы |
| `Math.sqr(16)` | `cannot find symbol` … `method sqr(int)` | такой функции нет, корень — `Math.sqrt` |
| `Math.Pi` | `cannot find symbol` … `variable Pi` | `Math.PI` — большими буквами |
| `Math.max(1, 2, 3)` | `no suitable method found for max(int,int,int)` | только два числа: `Math.max(Math.max(1, 2), 3)` |
| `int z = 5 / 0;` | при запуске: `ArithmeticException: / by zero` | на ноль делить нельзя |

Ошибки, на которые Java **не ругается**, а молча считает не то:

| Код | Что получится | Как надо |
|---|---|---|
| `3 ^ 2` | `1` | `^` — не степень (это действие над двоичными разрядами). Квадрат — `3 * 3` или `Math.pow(3, 2)` |
| `7 / 2 * 2.0` | `6.0` | целое деление случилось раньше; `7 * 2.0 / 2` → `7.0` |
| `640 / 100 * 15` | `90` | сначала умножай: `640 * 15 / 100` → `96` |
| `Math.round(x * 100) / 100` | целое число | дели на `100.0` |
| `(int) Math.random() * 6` | всегда `0` | скобки: `(int) (Math.random() * 6)` |
| `"Сумма: " + a + b` | цифры склеились | скобки: `"Сумма: " + (a + b)` |

## 11. Шпаргалка

| Что | Как |
|---|---|
| порядок действий | скобки → `* / %` → `+ -`, одинаковые — слева направо |
| дробный результат | дробное число — до первого деления: `7 * 2.0 / 2` |
| последняя цифра / без последней цифры | `n % 10` / `n / 10` |
| по кругу | `(hour + 5) % 24`; назад — `Math.floorMod(hour - 5, 24)` |
| деление с округлением вверх | `(a + b - 1) / b` |
| модуль, большее, меньшее | `Math.abs(x)`, `Math.max(a, b)`, `Math.min(a, b)` |
| степень, корень, π | `Math.pow(x, n)`, `Math.sqrt(x)`, `Math.PI` |
| округлить к ближайшему / вниз / вверх | `Math.round(x)` (`long`) / `Math.floor(x)` / `Math.ceil(x)` (`double`) |
| два знака после точки | `Math.round(x * 100) / 100.0` |
| случайное от 1 до 6 | `(int) (Math.random() * 6) + 1` |
| процент от числа | `price * percent / 100` — сначала умножить |

## 12. Вопросы

**1. Что напечатает `System.out.println(20 / 3 % 4);`?**

<details><summary>Ответ</summary>

`2`. `/` и `%` одного старшинства, поэтому слева направо: `20 / 3` → `6`, потом `6 % 4` → `2`.
</details>

**2. Что напечатает каждая строка?**

```java
System.out.println(7 / 2 * 2.0);
System.out.println(7 * 2.0 / 2);
System.out.println(1 / 3 * 3);
```

<details><summary>Ответ</summary>

`6.0`, `7.0`, `0`. В первой и третьей строке первым шагом делятся два целых числа, и дробная часть пропадает до того, как в выражении появится дробное.
</details>

**3. Как из числа `5831` получить цифру `8`?**

<details><summary>Ответ</summary>

`5831 / 100 % 10`. Деление на 100 отрезает две последние цифры (`58`), остаток от деления на 10 оставляет последнюю из оставшихся (`8`).
</details>

**4. Чем отличаются `Math.round(-2.5)`, `Math.floor(-2.5)`, `Math.ceil(-2.5)` и `(int) -2.5`?**

<details><summary>Ответ</summary>

`-2` (половина — к большему), `-3.0` (вниз), `-2.0` (вверх), `-2` (отрезать дробную часть). `round` даёт `long`, `floor` и `ceil` — `double`, поэтому у них `.0`.
</details>

**5. Почему `int a = Math.pow(2, 3);` не компилируется? Как исправить?**

<details><summary>Ответ</summary>

`Math.pow` возвращает `double` (`8.0`), а дробное в `int` Java сама не кладёт. Исправить: `int a = (int) Math.pow(2, 3);` или `double a = Math.pow(2, 3);`. А проще всего — `2 * 2 * 2`.
</details>

**6. Скидка 15 % на позицию за 90 рублей. Что напечатают `90 * 15 / 100` и `90 / 100 * 15`?**

<details><summary>Ответ</summary>

`13` и `0`. Во втором случае `90 / 100` — это `0`, и дальше ноль умножается на 15. Сначала умножай, потом дели. Точная скидка — 13.5, дробь отброшена: копейки посчитаем, когда дойдём до `BigDecimal` (день 42).
</details>

**7. Сколько коробок по 6 яиц нужно для 20 яиц? Напиши выражение без `Math`.**

<details><summary>Ответ</summary>

`(20 + 6 - 1) / 6` → `4`. Обычное `20 / 6` дало бы `3`, и двум яйцам не хватило бы места.
</details>

**8. Что выведет этот код?**

```java
System.out.println(5 / 0.0);
System.out.println(5 / 0);
```

<details><summary>Ответ</summary>

Первая строка напечатает `Infinity` (с дробными деление на ноль даёт бесконечность). Вторая уронит программу с `ArithmeticException: / by zero` — целые на ноль делить нельзя совсем.
</details>

**9. Что напечатает `System.out.println(3 ^ 2);`?**

<details><summary>Ответ</summary>

`1`, а не `9`. `^` в Java — не степень. Ошибки нет, поэтому такую ловушку легко не заметить. Квадрат — `3 * 3` или `Math.pow(3, 2)`.
</details>
