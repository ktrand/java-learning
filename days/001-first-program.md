# День 1. Первая программа

Сегодня: что такое программа, как её написать и запустить, как печатать текст и числа на экран и что делать, когда программа «не работает». В конце — 7 задач.

## 1. Что такое программа

Компьютер умеет выполнять очень простые команды: сложить два числа, запомнить значение, вывести символ на экран. **Программа** — это список таких команд, записанный по строгим правилам. Эти правила называются **языком программирования**. Java — один из таких языков. На ней пишут серверы банков и магазинов, Android-приложения и программы для касс.

Программу пишут обычным текстом в файле с расширением `.java`. Компьютер этот текст напрямую не понимает, поэтому запуск идёт в два шага:

```
Hello.java  ──компилятор──▶  Hello.class  ──JVM──▶  программа работает
 (твой текст)               (перевод для машины)
```

- **Компилятор** проверяет текст программы и переводит его в понятный машине вид. Если в тексте ошибка — компилятор откажется переводить и скажет, где ошибка.
- **JVM** (Java Virtual Machine, «виртуальная машина Java») выполняет переведённую программу.

Тебе не нужно делать эти шаги руками — IntelliJ делает их сама, когда ты нажимаешь «запустить».

## 4. Первая программа

Открой `src/main/java/sandbox/Playground.java` — это песочница, в ней можно писать что угодно. Напиши (лучше руками, а не копированием):

```java
package sandbox;

public class Playground {

    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

Слева от строки с `main` есть зелёный треугольник ▶. Нажми его → **Run 'Playground.main()'**. Внизу откроется окно **Run**, в нём:

```
Привет, мир!

Process finished with exit code 0
```

Первая строка — то, что напечатала программа. `exit code 0` значит «программа завершилась без ошибок».

Горячие клавиши: `Ctrl+Shift+F10` — запустить файл, который открыт; `Shift+F10` — запустить ещё раз то, что запускал последним.

### Что здесь написано

Пока это просто шаблон — каждое слово разберём в следующих уроках. Сейчас важно понять общую картину:

```java
package sandbox;                              // в какой папке лежит файл

public class Playground {                     // начало класса Playground
                                              //   (имя класса = имя файла)
    public static void main(String[] args) {  // отсюда программа начинает работу
        System.out.println("Привет, мир!");   // команда: напечатать строку
    }                                         // конец main
}                                             // конец класса
```

Правила, которые нужно запомнить сразу:

- **Фигурные скобки `{ }`** обозначают начало и конец блока. Каждая открытая скобка должна быть закрыта.
- **Точка с запятой `;`** ставится в конце каждой команды — как точка в конце предложения.
- **Регистр букв важен.** `System` и `system` — разные слова. Правильно — `System`.
- **Имя класса совпадает с именем файла.** `public class Playground` живёт в файле `Playground.java`.
- **Команды выполняются сверху вниз**, по порядку.
- **Отступы** (пробелы слева) компьютеру не важны, но без них код трудно читать. IntelliJ расставит их сама: `Ctrl+Alt+L`.

## 5. Печатаем на экран

### println и print

`System.out.println(...)` печатает то, что в скобках, и **переходит на новую строку**. `System.out.print(...)` печатает **без перехода** — следующий текст продолжит ту же строку.

```java
System.out.println("Первая строка");
System.out.println("Вторая строка");
System.out.print("Раз ");
System.out.print("два ");
System.out.println("три");
System.out.println();                // пустая строка
System.out.println("После пустой строки");
```

Вывод:

```
Первая строка
Вторая строка
Раз два три

После пустой строки
```

### Текст и числа

Текст пишут **в двойных кавычках** — это называется **строка**. Числа пишут без кавычек, и с ними Java умеет считать:

```java
System.out.println("2 + 2");   // в кавычках — просто текст
System.out.println(2 + 2);     // без кавычек — Java посчитает
System.out.println(42);
System.out.println(7 * 8);
```

Вывод:

```
2 + 2
4
42
56
```

Действия с числами: `+` сложение, `-` вычитание, `*` умножение, `/` деление. Порядок как в школе: сначала умножение и деление, потом сложение и вычитание. Скобки меняют порядок:

```java
System.out.println(2 + 3 * 4);     // 14
System.out.println((2 + 3) * 4);   // 20
```

Осторожно с делением: если оба числа целые, результат тоже целый — дробная часть просто отбрасывается. Если нужна дробь, напиши хотя бы одно число с точкой:

```java
System.out.println(10 / 3);     // 3
System.out.println(10.0 / 3);   // 3.3333333333333335
```

Подробно про числа и деление — на днях 2 и 3.

### Склеиваем текст и числа

Плюс между строкой и чем-то ещё **склеивает** их в одну строку:

```java
System.out.println("Итого: " + 270);            // Итого: 270
System.out.println("Кофе" + " " + "с молоком"); // Кофе с молоком
```

Здесь есть ловушка. Java выполняет плюсы слева направо:

```java
System.out.println("Сумма: " + 2 + 2);     // Сумма: 22
System.out.println("Сумма: " + (2 + 2));   // Сумма: 4
System.out.println(2 + 2 + " рубля");      // 4 рубля
```

В первой строке сначала `"Сумма: " + 2` → `"Сумма: 2"` (это уже текст), потом к тексту приклеивается ещё `2` → `"Сумма: 22"`. Скобки заставляют сначала посчитать. В третьей строке сначала идут два числа — они складываются как числа, а потом к результату приклеивается текст.

**Правило:** когда считаешь что-то внутри текста — бери вычисление в скобки.

### Особые символы

Как напечатать кавычку, если кавычка означает конец строки? Перед ней ставят обратную косую черту `\`. Такие пары называются **экранированием**:

| Пишешь | Получаешь |
|---|---|
| `\"` | кавычка `"` |
| `\\` | обратная черта `\` |
| `\n` | переход на новую строку |
| `\t` | табуляция (большой отступ) |

```java
System.out.println("Он сказал: \"Привет!\"");
System.out.println("C:\\projects\\java");
System.out.println("Строка 1\nСтрока 2");
System.out.println("Кофе\t150");
```

Вывод:

```
Он сказал: "Привет!"
C:\projects\java
Строка 1
Строка 2
Кофе	150
```

### Много строк сразу: текстовый блок

Если нужно напечатать несколько строк, можно не писать `println` много раз. Текстовый блок начинается с трёх кавычек `"""` и перехода на новую строку:

```java
System.out.println("""
        Меню:
          Кофе - 150
          Чай  - 90""");
```

Вывод:

```
Меню:
  Кофе - 150
  Чай  - 90
```

Общий отступ слева Java убирает сама, а отступы внутри (у «Кофе» и «Чай») остаются.

## 6. Комментарии

Комментарий — текст для человека, Java его пропускает:

```java
// это комментарий до конца строки
System.out.println("Привет"); // можно и после команды

/*
   а это комментарий
   на несколько строк
*/
```

Комментарий удобен, чтобы временно «выключить» строку: поставь курсор на строку и нажми `Ctrl+/` — IntelliJ добавит или уберёт `//`.

## 7. Когда программа не работает

Ошибки — нормальная часть работы, их делают все и постоянно. Главное — научиться их читать.

**Ошибка компиляции** — в тексте программы нарушены правила, и программа даже не запустится. IntelliJ подчёркивает такое место красным; наведи мышку — увидишь объяснение. При запуске внизу появится список ошибок.

Самые частые ошибки новичка и что пишет Java:

| Ошибка в коде | Сообщение Java | Что значит |
|---|---|---|
| `System.out.println("Привет")` | `';' expected` | забыл `;` в конце |
| `System.out.println("Привет);` | `unclosed string literal` | не закрыта кавычка |
| `system.out.println("Привет");` | `package system does not exist` | маленькая буква вместо большой |
| `System.out.printn("Привет");` | `cannot find symbol` | опечатка в названии команды |
| не хватает `}` в конце | `reached end of file while parsing` | файл кончился, а блок не закрыт |
| `public class Hello` в файле `Main.java` | `class Hello is public, should be declared in a file named Hello.java` | имя класса не совпадает с именем файла |

Как читать сообщение: `Playground.java:5: error: ';' expected` — файл `Playground.java`, **строка 5**, ошибка «ожидалась `;`». Иногда Java указывает на строку *после* настоящей ошибки — тогда посмотри и строкой выше.

Совет: исправляй **первую** ошибку из списка и запускай снова. Часто одна ошибка порождает несколько сообщений, и после исправления первой остальные пропадают.

## 8. Как проверять задачи

У каждой задачи есть тест — программа, которая запускает твоё решение и сравнивает то, что оно напечатало, с правильным ответом.

1. Открой `src/test/java/day01/Day01Test.java`.
2. Нажми зелёный двойной треугольник рядом с `class Day01Test` → **Run 'Day01Test'**.
3. Внизу появится список задач: зелёная галочка — решено, красный крестик — пока нет.
4. Нажми на красную задачу — справа будет сообщение вида:

```
Задача 1 печатает не то ==>
Expected :Привет, мир!
Actual   :
```

`Expected` — что должно быть, `Actual` — что напечатала твоя программа. Пустой `Actual` значит, что программа пока ничего не печатает. Ссылка **Click to see difference** покажет разницу по символам.

Тест строгий к тексту: важна каждая буква, пробел, запятая и регистр. Лишние пробелы в конце строк он прощает.

Из терминала (`Alt+F12` в IntelliJ) все задачи дня проверяются так:

```powershell
.\mvnw.cmd test "-Dtest=day01.*Test"
```

## 10. Вопросы

Ответь сам, потом открой ответ.

**1. Зачем нужен компилятор?**

<details><summary>Ответ</summary>

Он проверяет, что программа написана по правилам, и переводит её в вид, понятный JVM. Если в тексте ошибка, компилятор её покажет, и программа не запустится.
</details>

**2. Чем `print` отличается от `println`?**

<details><summary>Ответ</summary>

`println` после текста переходит на новую строку, `print` — нет, и следующий вывод продолжит ту же строку.
</details>

**3. Что напечатают эти две строки?**

```java
System.out.println("5 * 5");
System.out.println(5 * 5);
```

<details><summary>Ответ</summary>

```
5 * 5
25
```

В кавычках — текст как есть, без кавычек — Java считает.
</details>

**4. Что напечатает `System.out.println("Ответ: " + 3 + 4);`? Как получить `Ответ: 7`?**

<details><summary>Ответ</summary>

`Ответ: 34`. Плюсы выполняются слева направо: `"Ответ: " + 3` даёт текст `"Ответ: 3"`, к нему приклеивается `4`. Чтобы получить 7, нужны скобки: `"Ответ: " + (3 + 4)`.
</details>

**5. Что напечатает `System.out.println(7 / 2);`?**

<details><summary>Ответ</summary>

`3`. Оба числа целые, поэтому и результат целый, дробная часть отбрасывается. `7.0 / 2` даст `3.5`.
</details>

**6. Найди ошибки (их три):**

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет)
        system.out.println("Пока");
    }
```

<details><summary>Ответ</summary>

1. Не закрыта кавычка и нет `;` после `"Привет` — нужно `System.out.println("Привет");`.
2. `system` с маленькой буквы — нужно `System`.
3. Не хватает последней `}` — закрыть класс.
</details>

**7. Как напечатать строку `Путь: C:\new` и почему без подсказки не получится?**

<details><summary>Ответ</summary>

`System.out.println("Путь: C:\\new");`. Если написать `"C:\new"`, Java прочитает `\n` как переход на новую строку и напечатает `C:` и `ew` на разных строках.
</details>
