# День 2. Переменные и типы данных

Сегодня: как программе запоминать значения, какие бывают типы данных (целые числа, дробные, текст, да/нет), как менять значения и где Java может неожиданно ошибиться в расчётах. В конце — 7 задач.

## 1. Зачем нужны переменные

Вспомни задачу 6 из первого дня:

```java
System.out.println("Кофе x2 = " + 150 * 2);
System.out.println("Итого: " + (150 * 2 + 120 * 3));
```

Цена кофе `150` написана дважды. Подорожает кофе — придётся искать и менять все места, и одно обязательно забудешь. Решение — дать числу **имя** и дальше пользоваться именем:

```java
int coffeePrice = 150;
int croissantPrice = 120;

System.out.println("Кофе x2 = " + coffeePrice * 2);
System.out.println("Итого: " + (coffeePrice * 2 + croissantPrice * 3));
```

**Переменная** — это подписанная коробка, в которой лежит значение. Имя коробки — `coffeePrice`, внутри — `150`. Когда Java встречает имя переменной, она подставляет то, что лежит в коробке.

## 2. Как создать переменную

```java
int coffeePrice = 150;
```

| Часть | Что значит |
|---|---|
| `int` | **тип** — что можно положить в коробку (здесь — целое число) |
| `coffeePrice` | **имя** переменной |
| `=` | «положить в коробку» |
| `150` | **значение** |
| `;` | конец команды |

Знак `=` в программировании — не «равно», а **«положить»**. Правая часть вычисляется, результат кладётся в переменную слева.

Можно сначала создать переменную, а значение положить потом:

```java
int count;       // коробка есть, но пустая
count = 5;       // теперь в ней 5
```

### Значение можно менять

Тип при этом не пишут — переменная уже существует:

```java
int coffeePrice = 150;
System.out.println(coffeePrice);   // 150
coffeePrice = 170;                 // старое значение выброшено
System.out.println(coffeePrice);   // 170
```

Самая важная строчка дня:

```java
int count = 5;
count = count + 1;
System.out.println(count);   // 6
```

С точки зрения математики `count = count + 1` — бред. Но `=` — это «положить»: Java берёт **старое** значение `count` (5), прибавляет 1 и кладёт результат (6) обратно в `count`.

## 3. Типы данных

Java строго следит, что лежит в коробке: в коробку для целых чисел нельзя положить текст. Основные типы:

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число (примерно от −2,1 до +2,1 миллиарда) | `int age = 30;` |
| `long` | очень большое целое число | `long population = 8_100_000_000L;` |
| `double` | дробное число | `double price = 99.90;` |
| `boolean` | да или нет: `true` / `false` | `boolean isPaid = true;` |
| `char` | один символ, в **одинарных** кавычках | `char grade = 'A';` |
| `String` | текст любой длины, в **двойных** кавычках | `String name = "Анна";` |

```java
int age = 30;
long population = 8_100_000_000L;
double price = 99.90;
boolean isPaid = true;
char grade = 'A';
String name = "Анна";

System.out.println(age);          // 30
System.out.println(population);   // 8100000000
System.out.println(price);        // 99.9
System.out.println(isPaid);       // true
System.out.println(grade);        // A
System.out.println(name);         // Анна
System.out.println("Привет, " + name + "! Тебе " + age + " лет.");
// Привет, Анна! Тебе 30 лет.
```

Мелочи, о которые все спотыкаются:

- **Дробная часть отделяется точкой, а не запятой:** `99.90`, а не `99,90`.
- **Подчёркивания в числах** — только для красоты: `8_100_000_000` то же самое, что `8100000000`.
- **Буква `L` в конце** говорит «это число типа `long`». Без неё Java считает число `int` и ругается, если оно слишком большое.
- `99.90` печатается как `99.9` — лишние нули в конце Java не показывает.
- **`String` пишется с большой буквы**, остальные типы из таблицы — с маленькой. Почему так — узнаем, когда будем проходить классы.
- **`'A'` и `"A"` — разные вещи:** первое — символ (`char`), второе — строка (`String`) из одного символа.

### Как выбрать тип

- Количество, возраст, номер, цена в целых рублях → `int`.
- Что-то больше 2 миллиардов (население, миллисекунды) → `long`.
- Вес, рост, процент, среднее значение → `double`.
- Ответ «да/нет» (оплачен? открыто?) → `boolean`. Такие переменные обычно называют `isPaid`, `isOpen`, `hasDiscount`.
- Имя, адрес, сообщение → `String`.

### Сравнение даёт boolean

Знаки сравнения `>`, `<`, `>=`, `<=` дают `true` или `false`, и это можно положить в переменную:

```java
int coffeePrice = 170;
boolean expensive = coffeePrice > 160;
System.out.println("Дорого? " + expensive);   // Дорого? true
```

Подробно про сравнения и условия — на день 6.

## 4. Как называть переменные

Правила Java (нарушишь — ошибка):

- имя из букв, цифр и `_`, **не начинается с цифры**: `price2` можно, `2price` нельзя;
- без пробелов: `coffee price` нельзя;
- нельзя использовать слова самого языка: `int`, `class`, `public`, `double` и т. д.;
- регистр важен: `price` и `Price` — разные переменные.

Договорённости (не ошибка, но так пишут все):

- **английские слова**, понятные по смыслу: `coffeePrice`, а не `a`, `x1` или `cenaKofe`;
- **camelCase**: первое слово с маленькой, каждое следующее — с большой: `totalSum`, `isPaid`, `maxGuests`;
- русские буквы в именах Java разрешает, но так никто не делает.

| Имя | Можно? |
|---|---|
| `price` | да |
| `coffeePrice` | да, хороший стиль |
| `total_sum` | можно, но в Java так не пишут — лучше `totalSum` |
| `2price` | нет — начинается с цифры |
| `coffee price` | нет — пробел |
| `class` | нет — слово языка |

## 5. Короткие записи

Изменить переменную на какое-то число приходится постоянно, поэтому есть сокращения:

| Длинно | Коротко |
|---|---|
| `x = x + 5;` | `x += 5;` |
| `x = x - 3;` | `x -= 3;` |
| `x = x * 2;` | `x *= 2;` |
| `x = x / 4;` | `x /= 4;` |
| `x = x + 1;` | `x++;` |
| `x = x - 1;` | `x--;` |

```java
int x = 10;
x += 5;    // 15
x -= 3;    // 12
x *= 2;    // 24
x /= 4;    // 6
x++;       // 7
x--;       // 6
```

`++` и `--` пока пиши только отдельной командой, как выше. Внутри других выражений они ведут себя хитро — разберём позже.

## 6. Целые и дробные: деление

Если оба числа целые, **результат тоже целый** — дробная часть просто отбрасывается (не округляется!). Остаток от деления даёт знак `%`:

```java
int a = 7;
int b = 2;
System.out.println(a / b);   // 3   — целая часть
System.out.println(a % b);   // 1   — остаток
System.out.println(a / 2.0); // 3.5 — одно число дробное, значит и результат дробный
```

Если обе переменные целые, а нужен дробный результат, одну из них **превращают** в `double`. Это называется **приведение типа**: тип пишут в скобках перед значением.

```java
System.out.println((double) a / b);     // 3.5
System.out.println((double) (a / b));   // 3.0 — осторожно!
```

Во второй строке скобки заставили сначала разделить целые (`7 / 2` → `3`), и только потом готовая `3` превратилась в `3.0`. Поздно — дробная часть уже потеряна. **Превращай в `double` до деления.**

Обратное превращение — дробное в целое — просто отрезает дробную часть:

```java
System.out.println((int) 3.99);    // 3
System.out.println((int) -3.99);   // -3
```

### Что Java делает сама, а что только по твоей команде

- **Целое → дробное** — сама, ничего не теряется: `double d = 5;` → в `d` лежит `5.0`.
- **Дробное → целое** — только явно, через `(int)`. Иначе ошибка: Java не хочет молча терять дробную часть.

```java
double d = 5;          // можно, d = 5.0
int n = 99.90;         // ошибка: possible lossy conversion from double to int
int m = (int) 99.90;   // можно, m = 99
```

### Остаток от деления — очень полезная штука

- Чётное ли число: `x % 2` равно 0 — чётное.
- Последняя цифра: `1234 % 10` → `4`.
- Перевести секунды в минуты и секунды: `200 / 60` → `3` минуты, `200 % 60` → `20` секунд.

## 7. Где Java может «ошибиться»

### Переполнение

У `int` есть предел: 2 147 483 647. Если прибавить к нему 1, Java **не выдаст ошибку**, а молча перескочит на самое маленькое число — как механический счётчик, который после 999 показывает 000:

```java
int max = Integer.MAX_VALUE;     // готовая константа: самое большое int
System.out.println(max);         // 2147483647
System.out.println(max + 1);     // -2147483648

long bigger = max;               // int → long, Java делает сама
System.out.println(bigger + 1);  // 2147483648 — в long помещается
```

Если числа могут быть большими — бери `long`. Его предел — 9 223 372 036 854 775 807.

### Неточность дробных чисел

```java
System.out.println(0.1 + 0.2);   // 0.30000000000000004
System.out.println(1.1 * 3);     // 3.3000000000000003
```

Компьютер хранит дробные числа в двоичном виде, и многие привычные нам дроби (как 0.1) в нём записываются только приблизительно, — как 1/3 нельзя точно записать десятичной дробью. Для веса или процентов это не страшно. А **для денег `double` не используют** — для них в Java есть специальный тип `BigDecimal`, пройдём его на день 42. Пока считаем деньги в целых рублях (`int`).

## 8. Константы

Если значение не должно меняться никогда, пиши `final` — Java не даст его изменить:

```java
final int MAX_GUESTS = 40;
MAX_GUESTS = 50;   // ошибка: cannot assign a value to final variable MAX_GUESTS
```

Константы принято называть БОЛЬШИМИ_БУКВАМИ_ЧЕРЕЗ_ПОДЧЁРКИВАНИЕ.

## 9. var — пусть Java сама угадает тип

```java
var total = 660;        // Java видит целое число и делает переменную int
var name = "Анна";      // String
```

Тип всё равно есть и не меняется: `var total = 660;` потом `total = 2.5;` — ошибка. Пока пиши типы явно (`int`, `String`) — так лучше запоминаются. `var` пригодится позже, когда типы станут длинными.

## 10. Частые ошибки

| Код | Сообщение Java | Что не так |
|---|---|---|
| `int price; System.out.println(price);` | `variable price might not have been initialized` | в коробке ещё ничего нет |
| `int price = 150; int price = 170;` | `variable price is already defined in method main(String[])` | создал вторую переменную с тем же именем; для изменения тип не пишут: `price = 170;` |
| `int price = 99.90;` | `incompatible types: possible lossy conversion from double to int` | дробное в целое — только через `(int)` |
| `int count = "5";` | `incompatible types: String cannot be converted to int` | `"5"` — текст, а не число |
| `char c = "A";` | `incompatible types: String cannot be converted to char` | для `char` нужны одинарные кавычки: `'A'` |
| `long p = 8000000000;` | `integer number too large` | нужна буква `L`: `8000000000L` |
| `System.out.println(cofeePrice);` | `cannot find symbol` … `variable cofeePrice` | опечатка в имени (или переменная не создана) |
| `double price = 99,90;` | `<identifier> expected` | запятая вместо точки |
| `int 2price = 100;` | `not a statement` | имя начинается с цифры |
| `final int MAX = 40; MAX = 50;` | `cannot assign a value to final variable MAX` | константу менять нельзя |

## 11. Шпаргалка

| Что | Как |
|---|---|
| создать переменную | `int count = 5;` |
| изменить | `count = 10;` |
| увеличить | `count += 3;` или `count++;` |
| целое / большое целое / дробное | `int` / `long` (+ `L`) / `double` |
| да или нет | `boolean isOpen = true;` |
| символ / текст | `char c = 'A';` / `String s = "Текст";` |
| деление целых | `7 / 2` → `3`, остаток `7 % 2` → `1` |
| дробный результат | `(double) a / b` |
| отрезать дробную часть | `(int) 3.99` → `3` |
| самое большое int | `Integer.MAX_VALUE` |
| константа | `final int MAX_GUESTS = 40;` |

## 12. Вопросы

**1. Что будет в `x` после этих строк?**

```java
int x = 5;
x = x + 3;
x = x * 2;
```

<details><summary>Ответ</summary>

`16`. Сначала `5 + 3 = 8`, потом `8 * 2 = 16`. Каждый раз берётся текущее значение `x`.
</details>

**2. Какой тип выбрать: возраст; цена 99.90; имя; «оплачен ли заказ»; население Земли; первая буква фамилии?**

<details><summary>Ответ</summary>

`int`; `double` (а для настоящих денег позже — `BigDecimal`); `String`; `boolean`; `long`; `char`.
</details>

**3. Какие имена допустимы: `price`, `2price`, `totalSum`, `class`, `my price`, `price2`?**

<details><summary>Ответ</summary>

Допустимы `price`, `totalSum`, `price2`. Нельзя: `2price` (начинается с цифры), `class` (слово языка), `my price` (пробел).
</details>

**4. Что напечатает каждая строка, если `int a = 7; int b = 2;`?**

```java
System.out.println(a / b);
System.out.println(a % b);
System.out.println((double) a / b);
System.out.println((double) (a / b));
```

<details><summary>Ответ</summary>

`3`, `1`, `3.5`, `3.0`. В последней строке сначала выполняется деление целых (`3`), и только потом результат превращается в `3.0`.
</details>

**5. Почему `int x = 3.7;` — ошибка, а `double y = 3;` — нет?**

<details><summary>Ответ</summary>

Превращая `3.7` в целое, Java потеряла бы `.7`, поэтому требует сделать это явно: `(int) 3.7` (получится `3`). А превращение `3` в `3.0` ничего не теряет, и Java делает его сама.
</details>

**6. Чем `'A'` отличается от `"A"`?**

<details><summary>Ответ</summary>

`'A'` — один символ, тип `char`. `"A"` — строка, тип `String`, в которой один символ. Положить одно в переменную другого типа нельзя.
</details>

**7. Что напечатает этот код и почему?**

```java
int big = 2147483647;
big++;
System.out.println(big);
```

<details><summary>Ответ</summary>

`-2147483648`. Это переполнение: 2147483647 — максимум `int`, и после него счёт начинается с самого маленького числа. Ошибки при этом нет — поэтому переполнение опасно. Нужен `long`.
</details>

**8. Найди ошибки (их четыре):**

```java
int guests;
double price = 12,50;
String title = 'Кафе';
System.out.println(guests);
int guests = 10;
```

<details><summary>Ответ</summary>

1. `12,50` — нужна точка: `12.50`.
2. `'Кафе'` — текст пишется в двойных кавычках: `"Кафе"`.
3. `guests` печатается раньше, чем в неё что-то положили.
4. `int guests = 10;` — переменная `guests` уже создана в первой строке; чтобы положить значение, нужно `guests = 10;` (и сделать это до печати).
</details>

</details>
